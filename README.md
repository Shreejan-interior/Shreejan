# Shreejan Interiors

Static website for Shreejan Interiors.

## GitHub Pages

The site is deployed to [https://shreejan-interior.github.io/Shreejan/](https://shreejan-interior.github.io/Shreejan/).

GitHub Actions publishes the site whenever changes are pushed to `main`. The published artifact includes the HTML pages, styles, scripts, and `img/` assets.
